# 品类与视觉策略

先确定购买动机，再挑选构图。以下是候选方向，不是固定类别配色或风格。

## 跨品类决策

| 特征/目标 | 可用表达 | 约束 |
| --- | --- | --- |
| 瓶罐、盒装、器具等强轮廓 | 单品英雄、台面陈列 | 保持比例、盖子、标签及套装关系 |
| 布料、皮革、木纹等触感价值 | 实拍细节配主体，侧光 | 不创造新纹路 |
| 金属、玻璃、宝石等反光/透光 | 受控高光、边缘光、简洁环境 | 不抹掉结构，不把透明部分填实 |
| 日常使用价值 | 合理环境与真实尺度 | 不捏造用途，避免悬浮、接触错误 |
| 食用、闻香、清凉等感官动机 | 背景氛围、色彩与感官联想 | 联想与证实的原料/功能分开 |
| 多 SKU、多配件 | 分组陈列、清楚编号 | 先确认包含物，不把道具当赠品 |
| 优惠/活动 | 主体与利益点双重点 | 条件与利益一起可读，不虚构折扣 |

## 类别校验

| 类别 | 常用方向 | 保留/避免 |
| --- | --- | --- |
| 美妆个护 | 包装英雄、清洁质感 | 瓶形/喷头/标签；不暗示未提供的功效或配方 |
| 食品饮料、生鲜 | 真实食物、餐桌、温暖或清爽光线 | 份量/包装/已知原料；不臆造口味、零添加、产地 |
| 服饰鞋包 | 原产品陈列、搭配、纹理 | 版型/图案/拉链/鞋底；不改 Logo、颜色，模特路线按请求决定 |
| 数码家电 | 清楚结构、合理空间 | 接口/按钮/屏幕/数量；不杜撰续航、防水、降噪、兼容性 |
| 家具家居 | 空间比例、材质、生活情景 | 连接结构/木纹；无尺寸时不作精确尺度证明 |
| 珠宝钟表 | 微距、受控反射、留白 | 镶嵌/宝石数量/表盘；不新造证书、纯度、款式 |
| 母婴、宠物 | 温和生活场景、包装识别 | 适用年龄/对象/尺寸；不暗示无依据安全或健康保证 |
| 运动户外、工具工业件 | 功能环境、尺度可信 | 保护件/连接关系；不用装饰创造承载或性能证据 |
| 礼盒、组合商品 | 层次清楚的组合陈列 | 真实 SKU/数量/包装；道具与随箱物区分 |
| 未覆盖品类 | 按形态、材质、动机、环境匹配 | 先锁身份，再设计氛围 |

## 构图与适配

- 方形：保证单品与一个主信息识别；密集信息放次级图。
- 竖版：利用纵向层级，按用途预留上下安全区，避免文案挤压主体。
- 横幅：分配产品与文字区，不为放大商品裁掉关键结构。
- 系列：保持字体、配色、光线与身份，按各张目标变化构图；不同 SKU 使用对应原图。
- 白底图：优先完整外形、数量、自然阴影；用途允许时才加文案/道具。特定平台要求查官方来源。
